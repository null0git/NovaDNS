{{ icon('wifi') }}  If a device isn't resolving anything

1The device must be on port 53 — phones/PCs/routers never let you pick a custom port in their DNS settings, so the server has to be listening there. NovaDNS defaults to 53 now; check Settings → Network & Security to confirm.
2The host firewall must allow inbound UDP/TCP 53 from your LAN. See the commands below.
3The device must be on the same network as the server (same Wi-Fi/LAN) — a phone on cellular data won't reach a private IP.
4Easiest for "my phone and my PC": set the DNS server IP once in your router's DHCP settings so every device on the network picks it up automatically, instead of configuring each device by hand.
5Test from another machine on the network: dig @{{ ips[0] }} google.com (or nslookup google.com {{ ips[0] }} on Windows).
Host OSAllow inbound DNS (port 53)
Linux (ufw)sudo ufw allow 53/udp && sudo ufw allow 53/tcp
Linux (firewalld)sudo firewall-cmd --add-service=dns --permanent && sudo firewall-cmd --reload
Windows (PowerShell, admin)New-NetFirewallRule -DisplayName "NovaDNS" -Direction Inbound -Protocol UDP -LocalPort 53 -Action Allow
macOSsudo pfctl -d  (or allow port 53 in System Settings → Firewall → Options)
